# 指令和avx
x86 / x64 通用寄存器

64 位的 x86 处理器有 16 个通用寄存器：

RAX, RBX, RCX, RDX,
RDI, RSI, RBP, RSP,
R8 - R15
<br><br>
x86 的常见通用寄存器：

EAX, EBX, ECX, EDX,
EDI, ESI
这些寄存器在大多数指令中可以自由选用
<br><br>
特殊用途：
ESP : 保存当前函数栈顶（stack pointer）
EBP : 栈底寄存器（base pointer）
<br><br>
常见 x86 指令

INC 加 1 ： INC EAX  ; EAX = EAX + 1


TEST 与运算（不保存结果, 只修改标志位）：TEST EAX, EAX


LEA 装入有效地址：LEA DX, string

## 底层技术与矩阵
arma::mat 在内存优先列存储
`mem[in_row + in_col*n_rows] mat mm(ptr, 6, 6); `
 在内存中:mm(1, 1)和mm(0, 1)相邻,也就是说写法和我们操作二维数组是相反的

 为什么列存储? 因为全世界的矩阵库设计时，对底层行列式的计算约定就是这样的，不信你去翻openblas的源码

 ## 矩阵乘法
 一般的 GEMM 可以分解为多个对 GEPP、GEMP 或 GEPM 的调用<br>这些本身可以分解为多个对 GEBP、GEPB 或 GEPDOT 核的调用<br>
GEBP 是 General Matrix-Matrix Multiplication (GEMM) 的基本操作之一<br>

理想 cache 命中环境, 避免 DRAM 带宽限制<br>
matC(m x n) = matA(m x k) * matA(k x n) <br>
其中matB matC分解为N个列块 <br>
假设A：缓存足够放得下B、C的列块和整个matA <br>
假设B：如果B块 C块 A都在缓存中，则以CPU峰值速度计算 <br>
假设C：A持久在缓存<br>
